## Turn one teardown into a post

**X/LinkedIn thread skeleton**

```
I read <repo> so you don't have to. Here's the one idea worth stealing 🧵

1/ What it is: <one line>
2/ The pattern: <the architectural trick>
3/ Where it breaks: <honest limitation>
4/ Steal this: <the reusable bit>
5/ Full teardown + 170 more repos like this → github.com/rishivendhan84/github-resources
```

**Short-form / Reels / Shorts hook**

```
"This repo does <surprising thing> in <N> lines."
→ show the gitingest trick live
→ CTA: "full teardown in the repo, link in bio"
```

**Newsletter / blog section**

```
## <Repo> — <verdict>
- **What:** ...
- **Why it trended:** ...
- **The pattern:** ...
- **Verdict:** teardown / toolbox / vault-study / dropped
```

Every piece ends with the same link back to the repo. That loop — teardown → post → repo star — is the engine.
