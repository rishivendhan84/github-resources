# Contributing

Thanks for helping keep this list alive. Suggestions and PRs are both welcome.

## Suggest a repo (no PR needed)

Open an issue with the [**Suggest a repo**](../../issues/new?template=suggest-a-repo.md) template. Tell me:

- The repo or topic-hub link
- Which of the 16 domains it fits
- One line on **why it's worth someone's time** (this is the important part)

## Send a PR

1. Fork and add your entry to the right table in [`github-resources.md`](github-resources.md).
2. Keep the format: `| # | Project name | https://github.com/... |`
3. Renumber isn't required — I clean up numbering on merge.

## What gets accepted

✅ Real, maintained projects, or a `github.com/topics/...` hub when no single repo dominates
✅ Something with a clear learning or reuse angle
✅ Links that actually resolve

❌ Abandoned repos (no commits in 12+ months) unless they're a canonical reference
❌ Pure self-promotion with no substance
❌ Dead links or duplicates already in the list

## Teardown submissions

Want a repo torn down in the [daily log](teardowns/)? Open an issue titled `teardown: <repo>` with a sentence on the angle. Good candidates are trending, novel-architecture, or "everyone links it but nobody reads it" repos.
