A curated index of **170 GitHub repos and topic hubs across 16 domains**: AI agents, LLMs and RAG, generative AI, computer vision, NLP, recommender systems, reinforcement learning, full-stack web, mobile, security, blockchain, MLOps, IoT and edge, cloud and DevOps, research, and game development.

Useful as a starting point for project work, for finding reference implementations in an unfamiliar domain, or simply as a reading list.

**Tip:** swap `github.com` for `gitingest.com` in any repo URL to get the whole repo as one text blob, which makes it easy to feed to an LLM for a first-pass explanation.
